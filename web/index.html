Huffman coding, step by step

Huffman coding swaps each character for a string of 0s and 1s, shorter for common characters, using a tree built by joining the two rarest again and again. Press Play to watch the tree being built for the example text, or Step forward to join one pair at a time.

    More figures: the lower limit and the size as a file

    The lower limit (the entropy) is the fewest bits any code that handles one character at a time could use for this text. The file adds a table of code lengths and checksums so the text can be decoded and checked.

    How the codes are handed out

    The tree only decides how long each code is. The codes are then handed out in order, shortest first (canonical codes), so a decoder can rebuild them from the lengths alone. No code is the start of another, so the bits need no separators.
